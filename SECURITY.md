# Security

Subway Seat is mostly colour files, but a few pieces run code on your machine: `install.fish`, the Claude Code status line scripts, the GNOME Terminal setup scripts, and the Claude Code plugin's setup skill.

If you find a way any of them could do something unexpected (write outside the paths they claim, run injected input, leak data), please report it privately through [GitHub's security advisories](https://github.com/oddurs/subway-seat/security/advisories/new) rather than in a public issue. You'll get a reply within a week.
